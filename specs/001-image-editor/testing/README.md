## 🚀 快速测试流程

### 1. 启动开发服务器

```bash
npm run dev
```

访问: http://localhost:5173

---

### 2. 选择测试文档

**情况 A: 首次测试**
→ 阅读 `TESTING-GUIDE.md`，了解测试流程和关键点

**情况 B: 日常开发测试**
→ 使用 `test-execution-checklist.md`，快速验证功能

**情况 C: 正式验收测试**
→ 使用 `acceptance-test-plan.md`，完整测试所有场景

---

### 3. 执行测试

1. 打开测试文档
2. 准备测试图片 (3-5 张)
3. 按照清单逐项测试
4. 记录发现的问题
5. 填写测试结论

---

### 4. 报告问题

**问题严重性分类**:

- **Blocker**: 核心功能无法工作，阻塞发布
- **Critical**: 重要功能有问题，影响用户体验
- **Major**: 功能有缺陷但有替代方案
- **Minor**: 小问题，不影响主要功能
- **Trivial**: 优化建议

**问题报告位置**:

- 测试文档中的"问题记录"区域
- 或创建 `test-results/` 目录存放详细报告

## 🎯 测试策略

### 1. 冒烟测试 (Smoke Test)

**时间**: 5 分钟
**频率**: 每次构建后
**目标**: 验证核心功能可用

### 2. 功能测试 (Functional Test)

**时间**: 30 分钟
**频率**: 每个功能完成后
**目标**: 验证所有功能需求

### 3. 回归测试 (Regression Test)

**时间**: 15 分钟
**频率**: 修复 bug 后
**目标**: 确保修复未引入新问题

### 4. 验收测试 (Acceptance Test)

**时间**: 60 分钟
**频率**: 发布前
**目标**: 全面验证所有场景

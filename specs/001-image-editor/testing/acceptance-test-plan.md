## User Story 1: 多图片管理与基础操作 (P1)

### ✅ AS1-1: 加载多张图片

**Given**: 用户打开图片编辑器
**When**: 用户点击"加载图片"并选择 3 张图片
**Then**: 3 张图片应显示在画布上，每张图片可被独立选中

**测试步骤**:

1. 打开编辑器（确认处于编辑模式）
2. 点击工具栏的"加载图片"按钮
3. 选择 3 张不同的图片（JPEG/PNG）
4. 观察画布显示
5. 依次点击每张图片

**预期结果**:

- [ ] 所有 3 张图片成功加载到画布
- [ ] 图片显示清晰，无失真
- [ ] 每张图片可独立选中（显示边框/控制点）
- [ ] 右侧"图片"面板显示 3 张图片的缩略图

---

### ✅ AS1-2: 拖拽移动图片

**Given**: 画布上有多张图片
**When**: 用户选中一张图片并拖拽
**Then**: 该图片位置随鼠标移动而改变，其他图片位置不变

**测试步骤**:

1. 确认画布上有至少 2 张图片
2. 点击选中第一张图片
3. 按住鼠标拖拽图片到新位置
4. 释放鼠标
5. 观察其他图片是否移动

**预期结果**:

- [ ] 拖拽过程流畅，无卡顿
- [ ] 图片位置准确跟随鼠标
- [ ] 释放后图片停留在新位置
- [ ] 其他图片位置保持不变
- [ ] 画布缩放/平移后拖拽仍然正常

---

### ✅ AS1-3: 旋转图片

**Given**: 用户选中一张图片
**When**: 用户使用旋转控制旋转图片
**Then**: 图片按指定角度旋转，保持原有位置和尺寸

**测试步骤**:

1. 选中一张图片（激活 Transformer）
2. 切换到"选择"工具模式
3. 使用 Transformer 的旋转控制点旋转图片
4. 观察图片变化

**预期结果**:

- [ ] 图片可以自由旋转
- [ ] 旋转中心点为图片中心
- [ ] 图片质量无损失
- [ ] 旋转后位置和尺寸保持稳定

---

### ✅ AS1-4: 缩放图片

**Given**: 用户选中一张图片
**When**: 用户使用缩放控制调整大小
**Then**: 图片尺寸改变，保持宽高比例和中心位置

**测试步骤**:

1. 选中一张图片
2. 使用 Transformer 的角点控制点拖拽缩放
3. 观察图片尺寸变化

**预期结果**:

- [ ] 图片可以放大和缩小
- [ ] 缩放保持宽高比（按住 Shift 可能不保持）
- [ ] 图片中心位置保持稳定
- [ ] 图片质量清晰，无明显失真

---

### ✅ AS1-5: 删除图片

**Given**: 用户选中一张图片
**When**: 用户点击删除按钮
**Then**: 该图片从画布上移除，其他图片和标注不受影响

2. 选中第一张图片

**预期结果**:

- [ ] 选中的图片被移除
- [ ] 其他图片保持不变
- [ ] 标注节点和线段保持不变
- [ ] 右侧"图片"面板更新数量
- [ ] 可以用 Delete 键删除

---

### ✅ AS1-6: 图片选中状态

**Given**: 画布上有多张图片
**When**: 用户点击不同图片
**Then**: 被选中的图片显示操作控制，未选中的图片无控制显示

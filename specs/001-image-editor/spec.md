# Feature Specification: 图片编辑标注组件

**Feature Branch**: `001-image-editor`
**Created**: 2025-10-31
**Status**: Draft
**Input**: User description: "构建一个图片编辑组件。可以选择加载多个图片，图片支持拖拽、旋转、缩放、删除。支持在画布上进行点击标记序号节点，可以删除，支持划线并在线上标注尺寸信息，可以删除二次编辑等，支持导出图片，支持保存编辑的画布信息，可以二次加载编辑等功能，要区分编辑模式、查看模式，查看模式下所有标注的数据、图片都不可以编辑"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 多图片管理与基础操作 (Priority: P1)

用户需要在画布上管理多张图片，并对每张图片进行基本的位置和视觉调整操作。用户可以从本地选择并加载多张图片到画布，对图片进行拖拽移动、旋转角度、缩放大小，以及删除不需要的图片。

**Why this priority**: 这是组件的核心基础功能，没有图片加载和基础操作，后续的标注功能都无法实现。这是最小可用产品（MVP）的关键部分。

**Independent Test**: 可以通过加载多张测试图片，执行拖拽、旋转、缩放和删除操作，验证每个操作都能正确响应并反映在画布上。无需标注或保存功能即可独立测试。

**Acceptance Scenarios**:

1. **Given** 用户打开图片编辑器，**When** 用户点击"加载图片"并选择 3 张图片，**Then** 3 张图片应显示在画布上，每张图片可被独立选中
2. **Given** 画布上有多张图片，**When** 用户选中一张图片并拖拽，**Then** 该图片位置随鼠标移动而改变，其他图片位置不变
3. **Given** 用户选中一张图片，**When** 用户使用旋转控制旋转图片，**Then** 图片按指定角度旋转，保持原有位置和尺寸
4. **Given** 用户选中一张图片，**When** 用户使用缩放控制调整大小，**Then** 图片尺寸改变，保持宽高比例和中心位置
5. **Given** 用户选中一张图片，**When** 用户点击删除按钮，**Then** 该图片从画布上移除，其他图片和标注不受影响
6. **Given** 画布上有多张图片，**When** 用户点击不同图片，**Then** 被选中的图片显示操作控制（边框高亮/控制点），未选中的图片无控制显示

---

### User Story 2 - 序号节点标注 (Priority: P2)

用户需要在画布上的任意位置点击创建序号标记节点，用于标识关键位置或顺序。用户可以添加、删除这些序号节点，序号自动递增。

**Why this priority**: 标注功能是图片编辑器的核心增值功能，序号节点标注是最基础的标注类型，可以独立于其他标注功能实现和测试。

**Independent Test**: 在已加载图片的画布上，激活序号标注模式，点击多个位置创建序号节点，验证序号自动递增、节点可删除、删除后序号重新排序。

**Acceptance Scenarios**:

1. **Given** 用户在编辑模式下，**When** 用户激活"序号标注"模式并在画布上点击 3 次，**Then** 画布上出现 3 个序号节点，分别标记为 1、2、3
2. **Given** 画布上有 5 个序号节点（1-5），**When** 用户删除节点 3，**Then** 原节点 4、5 自动重新编号为 3、4
3. **Given** 画布上有序号节点，**When** 用户切换到非标注模式（如选择模式），**Then** 序号节点保持可见但不可被意外点击创建新节点
4. **Given** 用户创建序号节点时，**When** 节点位置与图片重叠，**Then** 节点显示在图片上层，清晰可见
5. **Given** 画布上有多个序号节点，**When** 用户选中某个节点，**Then** 该节点显示删除控制，可执行删除操作

---

### User Story 3 - 尺寸标注线 (Priority: P2)

用户需要在画布上绘制标注线，并在线上添加尺寸或描述信息。用户可以创建、编辑标注线的位置和文本信息，也可以删除标注线。

**Why this priority**: 尺寸标注是专业图片标注的重要功能，与序号节点同等重要但稍复杂，可以在序号节点功能稳定后实现。

**Independent Test**: 在画布上激活尺寸标注模式，绘制多条标注线，为每条线添加尺寸文本，验证线的绘制、文本编辑、删除和重新编辑功能。

**Acceptance Scenarios**:

1. **Given** 用户在编辑模式下，**When** 用户激活"尺寸标注"模式，点击起点并拖拽到终点，**Then** 画布上绘制一条标注线，显示线段和可编辑的文本输入框
2. **Given** 用户绘制了一条标注线，**When** 用户在文本框中输入"120cm"并确认，**Then** 标注线上显示"120cm"文本
3. **Given** 画布上有多条标注线，**When** 用户选中某条标注线，**Then** 该标注线高亮显示，显示删除和编辑控制
4. **Given** 用户选中一条标注线，**When** 用户点击"编辑"，**Then** 文本框重新激活，允许修改尺寸信息
5. **Given** 用户选中一条标注线，**When** 用户点击删除，**Then** 该标注线从画布上移除
6. **Given** 用户绘制标注线时，**When** 标注线的端点可以吸附到序号节点或图片边缘，**Then** 提供视觉反馈（高亮/对齐线）

---

### User Story 4 - 画布状态导出 (Priority: P3)

用户需要将编辑后的画布导出为图片文件，以及保存画布的所有编辑信息（图片、标注、位置等）以便后续继续编辑。

**Why this priority**: 导出和保存功能让用户能够持久化工作成果，是完整工作流的必要环节，但可以在核心编辑功能稳定后实现。

**Independent Test**: 在画布上完成图片和标注编辑后，执行导出图片操作，验证导出的图片包含所有可见内容。执行保存操作，验证保存的文件可以重新加载并恢复所有编辑状态。

**Acceptance Scenarios**:

1. **Given** 用户完成画布编辑，**When** 用户点击"导出图片"，**Then** 系统生成包含所有图片和标注的合成图片文件供下载
2. **Given** 用户完成画布编辑，**When** 用户点击"保存项目"，**Then** 系统生成包含所有图片数据、标注数据、位置信息的项目文件
3. **Given** 用户保存了项目文件，**When** 用户重新打开编辑器并加载该项目文件，**Then** 画布恢复到保存时的完整状态（所有图片、标注、位置）
4. **Given** 用户导出图片时，**When** 画布尺寸很大，**Then** 导出操作显示进度提示，不阻塞界面操作
5. **Given** 用户保存项目时，**When** 图片文件较大，**Then** 提供保存进度反馈

---

### User Story 5 - 编辑模式与查看模式切换 (Priority: P3)

用户需要在编辑模式和查看模式之间切换。编辑模式下可以进行所有操作，查看模式下所有内容只读，不可编辑。

**Why this priority**: 模式切换是用户体验优化功能，确保在演示或审阅时不会意外修改内容，但不影响核心编辑功能的实现。

**Independent Test**: 在画布上完成编辑后，切换到查看模式，验证所有编辑控制被隐藏且内容不可修改。切换回编辑模式，验证所有编辑功能恢复。

**Acceptance Scenarios**:

1. **Given** 用户在编辑模式下完成编辑，**When** 用户切换到"查看模式"，**Then** 所有编辑控制（删除按钮、拖拽手柄、旋转控制等）隐藏，画布内容只读
2. **Given** 用户在查看模式下，**When** 用户尝试点击图片或标注，**Then** 无任何编辑操作发生，内容保持不变
3. **Given** 用户在查看模式下，**When** 用户切换回"编辑模式"，**Then** 所有编辑控制恢复显示，可以继续编辑
4. **Given** 用户在查看模式下，**When** 用户执行缩放画布或平移视图操作，**Then** 这些查看操作仍然可用（不影响内容，仅影响视图）
5. **Given** 系统加载项目文件时，**When** 项目文件中指定了查看模式，**Then** 编辑器默认以查看模式打开

---

### Edge Cases

- **大量图片加载**：当用户尝试加载超过 20 张图片时，系统是否有性能提示或限制？
- **图片文件格式**：系统支持哪些图片格式（JPEG, PNG, WebP, SVG 等）？不支持的格式如何提示？
- **图片超大尺寸**：当单张图片文件超过 10MB 或分辨率超过 8K 时，系统如何处理加载和渲染性能？
- **标注数量限制**：当画布上标注节点或标注线数量很大（如超过 100 个）时，性能和交互体验如何保障？
- **重叠标注**：当多个序号节点或标注线重叠时，如何选中和操作特定的标注？
- **画布边界**：当图片或标注被拖拽到画布边界外时，如何处理？是否限制在画布内？
- **项目文件损坏**：当加载的项目文件格式错误或数据损坏时，如何提示用户并提供恢复选项？
- **导出失败**：当导出图片或保存项目因浏览器限制或磁盘空间不足失败时，如何提示和处理？
- **并发编辑**：如果未来支持多用户协作，如何处理冲突？（当前版本为单用户）
- **撤销/重做**：用户误操作后是否需要撤销功能？（建议但不在当前范围内）

## Requirements *(mandatory)*

### Functional Requirements

#### 图片管理

- **FR-001**: 组件 MUST 提供图片选择界面，允许用户从本地文件系统选择并加载一张或多张图片到画布
- **FR-002**: 组件 MUST 支持常见图片格式（JPEG, PNG, WebP），对不支持的格式显示错误提示
- **FR-003**: 加载的图片 MUST 在画布上可视化显示，每张图片作为独立图层
- **FR-004**: 系统 MUST 为每张图片提供唯一标识（ID），用于后续操作和数据管理

#### 图片操作

- **FR-005**: 用户 MUST 能够选中画布上的任意一张图片，选中状态有视觉反馈（如边框高亮）
- **FR-006**: 用户 MUST 能够通过拖拽移动选中的图片到画布任意位置
- **FR-007**: 用户 MUST 能够旋转选中的图片，旋转角度范围为 0-360 度
- **FR-008**: 用户 MUST 能够缩放选中的图片，缩放比例范围建议为 10%-500%
- **FR-009**: 用户 MUST 能够删除选中的图片，删除操作需要视觉确认（如删除按钮）
- **FR-010**: 图片操作（旋转、缩放）MUST 保持图片质量，避免模糊或失真

#### 标注功能 - 序号节点

- **FR-011**: 编辑模式下，用户 MUST 能够激活"序号标注"模式
- **FR-012**: 在序号标注模式下，用户点击画布任意位置 MUST 创建一个序号节点，序号自动递增（从 1 开始）
- **FR-013**: 序号节点 MUST 显示清晰的数字标识，样式一致且易于识别
- **FR-014**: 用户 MUST 能够选中并删除任意序号节点
- **FR-015**: 删除序号节点后，后续节点的序号 MUST 自动重新排序，保持连续性

#### 标注功能 - 尺寸标注线

- **FR-016**: 编辑模式下，用户 MUST 能够激活"尺寸标注"模式
- **FR-017**: 在尺寸标注模式下，用户通过点击起点并拖拽到终点 MUST 创建一条标注线
- **FR-018**: 标注线 MUST 显示线段和可编辑的文本区域，用于输入尺寸或描述信息
- **FR-019**: 用户 MUST 能够编辑标注线上的文本信息
- **FR-020**: 用户 MUST 能够选中并删除任意标注线
- **FR-021**: 用户 MUST 能够二次编辑已存在的标注线文本

#### 画布导出与保存

- **FR-022**: 用户 MUST 能够将当前画布状态（包括所有图片和标注）导出为单张图片文件
- **FR-023**: 导出的图片 MUST 包含所有可见内容，格式建议为 PNG 或 JPEG
- **FR-024**: 用户 MUST 能够保存当前画布的完整编辑信息（图片、标注、位置、角度、缩放等）为项目文件
- **FR-025**: 项目文件格式 MUST 是结构化的（建议 JSON），包含所有必要数据以便重新加载
- **FR-026**: 用户 MUST 能够加载之前保存的项目文件，恢复画布到保存时的完整状态

#### 模式切换

- **FR-027**: 组件 MUST 提供"编辑模式"和"查看模式"两种工作模式
- **FR-028**: 在编辑模式下，用户可以执行所有编辑操作（加载、移动、旋转、缩放、删除、标注）
- **FR-029**: 在查看模式下，所有编辑控制 MUST 被禁用或隐藏，画布内容只读
- **FR-030**: 用户 MUST 能够通过明确的控制（如切换按钮）在编辑模式和查看模式之间切换
- **FR-031**: 模式切换 MUST 立即生效，无需刷新或重新加载

#### 用户体验

- **FR-032**: 所有交互操作 MUST 提供即时的视觉反馈（如鼠标悬停高亮、选中状态、操作提示）
- **FR-033**: 组件 MUST 支持键盘快捷键（如 Delete 键删除选中对象，Esc 键取消选择）
- **FR-034**: 画布 MUST 支持缩放（Zoom In/Out）和平移（Pan）视图操作，不影响实际内容
- **FR-035**: 长时间操作（如导出大图、加载大项目）MUST 显示进度指示器

### Key Entities

- **Image（图片）**: 代表用户加载到画布的图片对象，包含属性：唯一 ID、图片源（URL/Data URL）、位置（x, y）、尺寸（width, height）、旋转角度（rotation）、缩放比例（scale）、层级（z-index）

- **AnnotationNode（序号节点）**: 代表画布上的序号标记点，包含属性：唯一 ID、位置（x, y）、序号（number）、样式（颜色、大小）

- **AnnotationLine（标注线）**: 代表画布上的尺寸标注线，包含属性：唯一 ID、起点（startX, startY）、终点（endX, endY）、文本内容（text）、样式（颜色、线宽、字体）

- **Canvas（画布）**: 代表整个编辑画布状态，包含属性：所有图片集合（images）、所有序号节点集合（annotationNodes）、所有标注线集合（annotationLines）、当前模式（mode: 'edit' | 'view'）、画布尺寸（canvasWidth, canvasHeight）

- **Project（项目）**: 代表可保存和加载的项目文件，包含属性：项目元数据（创建时间、版本）、Canvas 完整状态、项目名称

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户能够在 10 秒内加载 5 张图片到画布并看到显示结果
- **SC-002**: 用户能够在 5 秒内完成单张图片的拖拽、旋转、缩放操作，操作响应流畅无明显延迟
- **SC-003**: 用户能够在 1 分钟内完成 10 个序号节点和 5 条标注线的创建和编辑
- **SC-004**: 用户能够在 30 秒内导出包含所有内容的画布图片（画布尺寸 1920x1080）
- **SC-005**: 用户能够在 20 秒内保存项目文件，并在 15 秒内重新加载恢复完整状态
- **SC-006**: 90% 的用户能够在首次使用时无需文档指导即可完成基本操作（加载图片、标注、导出）
- **SC-007**: 编辑模式与查看模式切换响应时间小于 500 毫秒
- **SC-008**: 组件能够稳定处理包含 20 张图片和 50 个标注的画布，无性能降级

### Performance & UX Criteria *(based on constitution)*

- **PERF-001**: Web Vitals 满足标准 (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- **PERF-002**: Lighthouse 性能评分 > 90
- **UX-001**: 界面响应式设计在所有设备上一致（支持桌面端和平板端，移动端查看模式）
- **UX-002**: 符合 WCAG 可访问性标准（所有操作控制可通过键盘访问，色彩对比度达标）
- **QUALITY-001**: TypeScript 类型检查 100% 通过
- **QUALITY-002**: 测试覆盖核心业务逻辑（图片操作、标注创建、模式切换、导出保存）

## Assumptions

1. **单用户场景**：当前版本假设为单用户本地编辑，不涉及多用户协作或云端同步
2. **浏览器环境**：组件运行在现代浏览器（Chrome, Firefox, Safari, Edge 最新两个版本）
3. **图片尺寸合理**：假设用户加载的图片尺寸合理（单张 < 10MB，分辨率 < 8K），超大图片可能影响性能
4. **本地存储**：项目文件保存到用户本地，使用浏览器下载 API，不涉及服务器端存储
5. **Canvas 渲染**：组件基于 HTML5 Canvas 或 SVG 技术实现（具体技术选型在实现阶段确定）
6. **撤销重做**：当前版本不包含撤销/重做功能，可作为未来增强功能
7. **默认样式**：序号节点和标注线使用默认样式（颜色、字体、线宽），用户暂不支持自定义样式
8. **导出格式**：导出图片默认为 PNG 格式，保证透明度和质量
9. **项目文件格式**：项目文件为 JSON 格式，文件扩展名为 `.json` 或自定义扩展名（如 `.iep` - Image Editor Project）
10. **吸附辅助**：标注线绘制时提供智能吸附（吸附到节点或图片边缘），提升标注精度
